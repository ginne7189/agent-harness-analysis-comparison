# Comparison Record Contract

대안 또는 분석 관점마다 다음 값을 전달합니다.

- `option`: 비교 대상
- `criterion`: 비교 기준
- `observed_value`: 확인한 값 또는 내용
- `unit`: 단위와 측정 기준
- `evidence`: 출처와 근거
- `calculation`: 계산식 또는 산출 방법
- `assumptions`: 전제와 추정
- `confidence`: high·medium·low
- `limitations`: 데이터 공백과 해석 한계
- `counter_evidence`: 반대 근거 또는 불리한 정보
- `status`: confirmed·unknown·conflict

같은 기준에 서로 다른 단위가 사용되면 비교 전에 변환 방법을 확인합니다.
