# 분석·비교 도메인 설계 체크리스트

- [ ] 이 비교가 지원할 실제 의사결정 질문을 한 문장으로 썼는가
- [ ] 비교 대상과 제외 대상을 고정했는가
- [ ] 결과를 보기 전에 비교 기준과 가중치를 정했는가
- [ ] 기준별 측정 방법·단위·기간이 같은가
- [ ] 사실·계산·추정·의견을 구분하는가
- [ ] 모든 대안에 같은 Result Contract를 사용하는가
- [ ] 데이터 없음과 0을 구분하는가
- [ ] 유리한 근거뿐 아니라 반대 근거도 수집하는가
- [ ] 가중치를 바꿨을 때 결론이 달라지는지 확인하는가
- [ ] 분석 결과와 최종 의사결정의 책임을 분리했는가
- [ ] 자동 반복 횟수와 실패 후 사람 검토 조건을 정했는가
